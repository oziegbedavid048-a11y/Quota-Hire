## 🛠 How to Use in Email Clients

### 1. Gmail / Google Workspace
1. Open [`email_signatures/index.html`](file:///c:/Users/David/Desktop/QOUTA%20HIRE/email_signatures/index.html) in your browser.
2. Click **"Copy Signature"** for your desired email address.
3. Open Gmail &rarr; Settings &rarr; See all settings &rarr; General &rarr; **Signature**.
4. Paste (`Ctrl+V` or `Cmd+V`) into the signature text field and save.

### 2. Outlook / Webmail
1. Click **"Copy Signature"** in the dashboard.
2. Go to Outlook Settings &rarr; Mail &rarr; Compose and reply &rarr; Signature.
3. Paste directly into the signature box.

### 3. ZeptoMail / Automated Mailers / HTML Code
1. Open the `.html` file (e.g., [`hello_quotahire.html`](file:///c:/Users/David/Desktop/QOUTA%20HIRE/email_signatures/hello_quotahire.html)).
2. Copy the entire raw HTML source code or click **"Copy HTML Code"** in the dashboard.
3. Paste into your HTML template editor.
