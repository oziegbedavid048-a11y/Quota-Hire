How to Install Signature in Your Email Client

  1. Gmail / Google Workspace: Open Gmail → Settings (Gear Icon) → See all settings → General → Signature. Click Copy Signature button above, then paste directly into the signature text editor box. Save changes.
  2. Outlook (Web or Desktop): Settings → View all Outlook settings → Mail → Compose and reply → Signature. Paste the copied signature directly into the box.
  3. Apple Mail (Mac): Preferences → Signatures. Create a new signature, uncheck "Always match my default font", and paste the signature.
  4. ZeptoMail / Automated Mailers: Click Copy HTML Code button above and paste the raw HTML into your ZeptoMail or email template editor.
